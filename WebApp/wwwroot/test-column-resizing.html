Test Instructions:

  1. Hover your mouse over any column header to activate resize detection
  2. Move your mouse to the far right edge of the header (within 10px of the right border)
  3. You should see the cursor change to a col-resize cursor and a blue resize handle appear
  4. Click and drag the handle to resize the column
  5. The column should resize smoothly and the table should adjust accordingly
  6. Try resizing multiple columns to ensure they all work
  7. Try sorting and paging to ensure the resize functionality doesn't interfere
  8. Move your mouse away from the header or edge to hide the resize handle

Expected Behavior:

  • Resize handles should only appear when mouse is near the right edge of visible, sortable columns
  • Cursor should change to col-resize when near the edge
  • Columns should have a minimum width of 20px
  • The table should maintain proper layout during and after resizing
  • Other DataTables features (sorting, paging, etc.) should continue to work normally
  • No JavaScript errors should occur in the console
  • Resize handle should disappear when mouse moves away from the edge
